## Considerations for user registration

When it comes to user registrations, there are trade-offs between ease of use and thus user growth on the one hand and a higher barrier to entry but also fewer moderation requirements on the other.

Servers that enable fully open registrations, meaning that anyone can make an account, make it the easiest for users to sign up, but it is a trade-off with increased exposure to potentially bad actors. Therefore, fully open registration servers have the responsibility to invest adequately in moderation capacity.
